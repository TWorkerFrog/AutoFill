# AutoFill

**AutoFill** — приложение для массового заполнения грамот и дипломов. Вы
выбираете шаблон JPG/PNG, список ФИО и шрифт, настраиваете положение текста —
программа создаёт готовые PNG или PDF.

Обработка идёт в отдельном потоке: окно остаётся отзывчивым, прогресс виден,
генерацию можно отменить.

---

## Возможности

- 🖼 **Шаблон** — JPG, JPEG или PNG, с учётом EXIF-поворота и DPI.
- ✍️ **Шрифты** — системные семейства с начертаниями или свой TTF/OTF/TTC.
- 🎨 **Оформление текста** — размер, цвет, межбуквенный и межстрочный интервал.
- 📋 **Список ФИО** — вставка из Excel/Блокнота или загрузка TXT/CSV.
- 🔍 **Поиск по списку** — пока фильтр активен, список защищён от случайного
  редактирования, а кнопка очистки отключена.
- ⚠️ **Исключения** — ФИО, которые не помещаются в поля для печати, можно
  собрать в отдельном списке и затем перенести обратно.
- 📐 **Точная позиция** — автоцентрирование, смещения, выбор точки на шаблоне.
- 👁 **Живой предпросмотр** — справа от настроек; двойной клик открывает
  редактор с зумом.
- 🖱 **Редактор** — на шаблоне сразу видны поля для печати, текущий текст и
  маркер; размер и цвет текста меняются прямо в нём.
- 📄 **PNG или PDF** — отдельный файл на каждого человека, общий PDF постранично
  или один PDF на всех.
- 🔁 **Конфликты имён** — заменить, создать с номером, пропустить или отменить.
- 🧹 **Безопасная очистка** — удаляются только файлы, созданные AutoFill и
  записанные в манифест; выбранный шаблон, чужие файлы и папки не затрагиваются.
- 🌗 **Темы** — тёмная, светлая или системная.
- 💾 **Настройки** — сохраняются в профиль пользователя и восстанавливаются при
  следующем запуске.
- 🧵 **Фоновая генерация** — прогресс, отмена и отчёт об ошибках без зависания UI.

## Быстрый старт

1. **Выберите шаблон** — кнопка «Выбрать» рядом с полем шаблона.
2. **Выберите шрифт** — начните вводить название семейства и выберите подсказку
   или нажмите «Файл» и укажите свой TTF/OTF/TTC.
3. **Настройте размер, цвет и интервалы** на вкладке «Основные».
4. **Вставьте ФИО** — каждая строка это один человек:
   `Иванов Иван Иванович`.
5. **Проверьте позицию** на вкладке «Позиция» или откройте редактор.
6. **Выберите формат** на вкладке «Вывод».
7. Нажмите **«Сгенерировать»**.

По умолчанию файлы сохраняются в `Документы\AutoFill`. Папку можно изменить на
вкладке «Вывод» или через меню «Файл».

## Список ФИО и поиск

- Каждая непустая строка — отдельный человек; слова разделяются пробелами.
- Кнопка **«Загрузить файл»** читает TXT/CSV в UTF-8, UTF-16 или CP1251.
- При активном поиске редактор списка становится **только для чтения**. Это
  сделано специально: иначе можно было бы случайно удалить скрытые строки.
- Кнопка очистки на время поиска отключена; очистить список можно после сброса
  фильтра.
- Дубликаты имён обнаруживаются перед генерацией. Их можно удалить или
  оставить — тогда для совпадающих имён будут созданы файлы с номерами.

### Исключения

Если текст не помещается в границы, AutoFill предложит:

- сгенерировать все грамоты;
- сгенерировать только корректные;
- отменить операцию.

При выборе «Только корректные» проблемные ФИО попадают в список исключений.
Позже их можно перенести в основной список кнопкой
**«Перенести в основной список»**.

## Позиция и поля для печати

На вкладке «Позиция» доступны:

- автоцентрирование по X и/или Y;
- точные координаты X/Y;
- смещения X/Y;
- выравнивание строк: слева, по центру, справа;
- поля для печати;
- кнопка **«Открыть редактор»**.

В редакторе:

- **правая кнопка мыши** — поставить маркер;
- **левая кнопка** — перемещать изображение;
- **колесо** — зум;
- **стрелки** — сдвиг на 1 px;
- **Shift + стрелки** — 10 px;
- **Ctrl + стрелки** — 50 px;
- **Alt + движение мыши** — расстояние до маркера;
- **«В центр»** — вернуть маркер в центр изображения;
- размер, цвет и межбуквенный интервал текста;
- поля для печати и их отображение.

Пунктирная рамка показывает поля для печати, а текст рисуется в текущем шрифте,
размере и цвете. Если точку действительно меняли, автоцентрирование по X/Y
отключается, чтобы координаты применялись. При изменении только шрифта или цвета
автоцентрирование сохраняется.

## Формат имени

На вкладке «Формат имени» можно выбрать:

- **Одна строка** — все ФИО в одну строку.
- **Фамилия отдельно** — фамилия на первой строке, остальное на второй.
- **Каждое слово отдельно** — до трёх строк.
- **Своё разбиение** — указать, после какого слова переносить.
- **Авто** — перенос по словам с учётом реальной ширины шрифта и полей для печати.
  Количество строк не ограничено двумя.

Перед генерацией проверяются левая, правая, верхняя и нижняя границы с учётом
смещений и межстрочного интервала.

## Вывод

### PNG

Для каждого ФИО создаётся отдельный PNG. DPI берётся из шаблона; если метаданных
нет — используется 150 DPI.

### PDF

- **Каждому свой PDF** — отдельный файл на человека.
- **Один общий PDF** — все страницы в одном файле. Для сборки используется
  `pypdf`; если библиотека недоступна, применяется резервный путь через Pillow.

### Конфликты имён

Если файл уже существует, можно выбрать:

- заменить;
- создать файл с номером (`Иванов_Иван_2.png`);
- пропустить;
- отменить всю операцию.

Для общего PDF доступны те же варианты.

### Очистка предыдущих файлов

Опция удаляет только файлы, перечисленные в
`.autofill-manifest.json` внутри папки вывода. Выбранный шаблон защищён
отдельно и не удаляется, даже если он попал в манифест. Чужие файлы, вложенные
папки и файлы вне папки не удаляются. Если какой-то файл занят и не удалился,
он остаётся в манифесте для следующей попытки.

## Данные приложения

Настройки, журнал и кеш шрифтов хранятся в профиле пользователя:

- Windows: `%LOCALAPPDATA%\AutoFill\`
- macOS/Linux: `~/.autofill/` или `%APPDATA%`, если переменная задана.

Основные файлы:

- `settings.json` — настройки;
- `settings.json.bak` — предыдущая версия настроек;
- `logs\app.log` — журнал с ротацией;
- `fonts_cache.json` — кеш системных шрифтов.

Повреждённый файл настроек не удаляется безвозвратно: он переименовывается в
`settings.json.corrupt-<время>`.

## Установка готовой сборки

1. Скачайте `AutoFill.exe` из раздела Releases или соберите его самостоятельно.
2. Запустите файл. Установка не обязательна.
3. При первом запуске Windows может показать предупреждение SmartScreen —
   проверьте источник файла.

Для установщика используется `setup.iss` (Inno Setup). Он создаёт ярлыки и
устанавливает приложение в профиль пользователя, без запроса прав
администратора.

---

## Запуск из исходников

Требуется Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m compileall -q main.py core ui build.py
python main.py
```

Для разработки:

```powershell
python -m pip install -r requirements-dev.txt
```

## Сборка

```powershell
python build.py
```

Скрипт:

- перекомпилирует `resources.qrc` в `resources_rc.py`;
- удалит старые `build/` и `dist/`;
- соберёт `dist/AutoFill.exe` через PyInstaller;
- включит `style.qss`, `pypdf` и подмодули `fontTools`.

Иконка приложения — `icons/app_icon.ico`.

### Установщик

Если установлен [Inno Setup 6](https://jrsoftware.org/isinfo.php):

```powershell
iscc setup.iss
```

Результат: `dist\AutoFill_Setup_1.1.0.exe`.

## Проверки

```powershell
python -m unittest discover -s tests -v
ruff check .
```

Тесты покрывают измерение и отрисовку текста, безопасные имена и манифест,
настройки, генерацию PNG/PDF, конфликты, отмену и резервную сборку PDF без
`pypdf`.

Интерфейс дополнительно проверяется локальным headless smoke-скриптом; он не
входит в поставку и не коммитится.

## Ограничения

- Для TTC-коллекций используется первое начертание; отдельные лица коллекции
  могут быть недоступны по имени.
- Отмена генерации срабатывает между файлами/страницами. Один очень большой
  рендер может завершиться перед остановкой.
- Импорт напрямую из Excel/Word не поддерживается: используйте TXT/CSV или
  вставку текста.
- Список ФИО и исключения не сохраняются в настройках автоматически.
- На не-Windows системная тема определяется через доступный Qt-сигнал; если он
  недоступен, используется тёмная тема.

# AutoFill

**AutoFill** – приложение для массового заполнения грамот и дипломов.
Выберите шаблон JPG/PNG, вставьте список ФИО, настройте шрифт и положение
текста – программа создаст готовые файлы: PNG или PDF на каждого человека
либо один общий PDF.

Генерация идёт в отдельном потоке: окно остаётся отзывчивым, прогресс виден,
операцию можно отменить в любой момент.

---

## Возможности

- **Шаблон** – JPG, JPEG или PNG с учётом EXIF-поворота и DPI.
- **Шрифты** – системные семейства с выбором начертания или свой файл
  TTF/OTF/TTC.
- **Оформление текста** – размер, цвет, межбуквенный и межстрочный интервал,
  цвет маркера и линии полей для печати.
- **Список ФИО** – вставка из Excel или Блокнота, загрузка TXT/CSV в UTF-8,
  UTF-16 или CP1251.
- **Поиск по списку** – пока фильтр активен, список защищён от случайного
  редактирования, а кнопка очистки отключена.
- **Исключения** – ФИО, которые не помещаются в поля для печати, собираются
  в отдельный список и возвращаются в основной одним нажатием.
- **Точная позиция** – авто-позиционирование по X и Y, точные координаты,
  смещения и выбор точки прямо на шаблоне.
- **Живой предпросмотр** – справа от настроек; двойной клик открывает
  редактор с зумом.
- **Редактор грамоты** – на шаблоне сразу видны поля для печати, текст и
  маркер; шрифт можно выбрать из списка, набрать название с клавиатуры или
  указать файл; размер, цвет и интервалы меняются на месте.
- **Формат вывода** – PNG или PDF: отдельный файл на каждого человека,
  общий PDF постранично или один файл на всех.
- **Конфликты имён** – заменить, создать файл с номером, оставить
  существующие или отменить операцию.
- **Безопасная очистка** – удаляются только файлы, созданные AutoFill и
  записанные в манифест; шаблон и чужие файлы не затрагиваются.
- **Темы** – тёмная, светлая или системная; диалоги выбора файла и цвета –
  нативные, в стиле Windows.
- **Настройки** – сохраняются в профиле пользователя и восстанавливаются при
  следующем запуске.
- **Фоновая генерация** – прогресс, отмена и подробный отчёт об ошибках без
  зависания интерфейса.

## Быстрый старт

1. **Выберите шаблон** – кнопка «Обзор» рядом с полем шаблона.
2. **Выберите шрифт** – начните вводить название семейства и выберите
   подсказку, либо нажмите «Обзор» и укажите свой TTF/OTF/TTC.
3. **Настройте размер, цвет и интервалы** на вкладке «Основные».
4. **Вставьте ФИО** – каждая строка соответствует одному человеку,
   например `Иванов Иван Иванович`.
5. **Проверьте позицию** на вкладке «Позиция» или откройте редактор.
6. **Выберите формат** на вкладке «Вывод».
7. Нажмите **«Сгенерировать»**.

По умолчанию файлы сохраняются в `Документы\AutoFill`. Папку можно изменить
на вкладке «Вывод».

Строки меню нет – все действия вынесены на вкладки, а горячие клавиши
продолжают работать. Быстрая справка открывается кнопкой **«?»** в правом
верхнем углу вкладок.

## Список ФИО и поиск

- Каждая непустая строка – отдельный человек; слова разделяются пробелами.
- Кнопка **«Загрузить файл»** читает TXT/CSV в UTF-8, UTF-16 или CP1251.
- При активном поиске редактор списка становится **только для чтения**:
  иначе можно случайно потерять скрытые фильтром строки.
- Кнопка очистки на время поиска отключена; очистить список можно после
  сброса фильтра.
- Дубликаты имён обнаруживаются перед генерацией. Их можно удалить или
  оставить – тогда для совпадающих имён будут созданы файлы с номерами.

### Исключения

Если текст не помещается в поля для печати, AutoFill предложит:

- сгенерировать все грамоты;
- сгенерировать только корректные;
- отменить операцию.

При выборе «Только корректные» проблемные ФИО попадают в список исключений.
Позже их можно вернуть в основной список кнопкой
**«Перенести в основной список»**.

## Позиция и поля для печати

На вкладке «Позиция» доступны:

- авто-позиционирование по X с учётом выравнивания и автоцентрирование по Y;
- точные координаты X/Y;
- смещения X/Y;
- выравнивание строк: слева, по центру, справа;
- поля для печати;
- кнопка **«Открыть редактор»**.

В редакторе:

- **правая кнопка мыши** – поставить маркер;
- **левая кнопка** – перемещать изображение;
- **колесо** – зум;
- **стрелки** – сдвиг на 1 px;
- **Shift + стрелки** – 10 px;
- **Ctrl + стрелки** – 50 px;
- **Alt + движение мыши** – расстояние до маркера;
- **«В центр»** – вернуть маркер в центр изображения;
- галочки авто-позиционирования по X и автоцентрирования по Y;
- цвет крестика и линии полей для печати;
- размер, цвет и межбуквенный интервал текста;
- поля для печати и их отображение.

Тонкая сплошная рамка показывает поля для печати; её цвет и цвет маркера
выбираются в инспекторе. Текст рисуется в текущем шрифте, размере и цвете.
Если точку действительно меняли, авто-режимы по X/Y отключаются, чтобы
координаты применялись. При изменении только шрифта или цвета авто-режимы
сохраняются. В авто-режиме по X блок прижимается к выбранному краю (слева
или справа) либо центрируется, если выбрано «По центру».

## Формат имени

На вкладке «Имя» можно выбрать режим формирования строк:

- **В одну строку** – все ФИО в одну строку.
- **Фамилия отдельно** – фамилия на первой строке, остальное на второй.
- **Каждое слово отдельно** – до трёх строк.
- **Свой вариант** – указать, после какого слова переносить.
- **Авто** – перенос по словам с учётом реальной ширины шрифта и полей для
  печати; количество строк не ограничено двумя.

Перед генерацией проверяются левая, правая, верхняя и нижняя границы с учётом
смещений и межстрочного интервала.

## Вывод

### PNG

Для каждого ФИО создаётся отдельный PNG. DPI берётся из шаблона; если
метаданных нет, используется 150 DPI.

### PDF

- **Каждому свой PDF** – отдельный файл на человека.
- **Один общий PDF** – все страницы в одном файле. Для сборки используется
  `pypdf`; если библиотека недоступна, применяется резервный путь через
  Pillow.

### Конфликты имён

Если файл с таким именем уже существует, программа спросит, что делать:

- **Заменить** – перезаписать существующий файл;
- **Создать с номером** – сохранить как `Иванов_Иван_2.png`;
- **Оставить существующие** – старые файлы не пересоздаются, остальные ФИО
  будут сгенерированы;
- **Отмена** – прервать операцию.

Решение применяется ко всей пачке сразу, включая общий PDF.

### Очистка предыдущих файлов

Опция «Удалить файлы, созданные AutoFill при прошлых генерациях» стирает
только файлы, перечисленные в манифесте `.autofill-manifest.json` внутри
папки вывода – это список всего, что AutoFill создал сам. Выбранный шаблон
защищён отдельно и не удаляется, даже если попал в манифест. Чужие файлы,
вложенные папки и файлы вне папки не затрагиваются. Если какой-то файл занят
и не удалился, он остаётся в манифесте до следующей попытки.

## Данные приложения

Настройки, журнал и кеш шрифтов хранятся в профиле пользователя:

- Windows: `%LOCALAPPDATA%\AutoFill\`;
- macOS/Linux: `~/.autofill/` или `%APPDATA%`, если переменная задана.

Основные файлы:

- `settings.json` – настройки, включая цвета полей и маркера;
- `settings.json.bak` – предыдущая версия настроек;
- `logs\app.log` – журнал с ротацией;
- `fonts_cache.json` – кеш системных шрифтов.

Цвета линии полей и маркера сохраняются автоматически после закрытия
редактора, даже если потом выйти без отдельного сохранения. Повреждённый
файл настроек не удаляется безвозвратно: он переименовывается в
`settings.json.corrupt-<время>`.

| `Ctrl+Shift+O` | Загрузить список ФИО |

## Установка готовой сборки

1. Скачайте `AutoFill.exe` из раздела Releases или соберите его сами.
2. Запустите файл – установка не обязательна.
3. При первом запуске Windows может показать предупреждение SmartScreen,
   поэтому проверяйте источник файла.

Для установщика используется `setup.iss` (Inno Setup). Он создаёт ярлыки и
устанавливает приложение в профиль пользователя без прав администратора.

---

## Запуск из исходников

Требуется Python 3.12+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m compileall -q main.py core ui build.py
python main.py
```

Для разработки:

```powershell
python -m pip install -r requirements-dev.txt
```

---

## Сборка

```powershell
python build.py
```

Скрипт:

- перекомпилирует `resources.qrc` в `resources_rc.py`;
- удаляет старые `build/` и `dist/`;
- собирает `dist/AutoFill.exe` через PyInstaller;
- включает `style.qss`, `pypdf` и подмодули `fontTools`.

Иконка приложения: `icons/app_icon.ico`.

### Установщик

Если установлен [Inno Setup 6](https://jrsoftware.org/isinfo.php):

```powershell
iscc setup.iss
```

Результат: `dist\AutoFill_Setup_1.1.0.exe`.

## Проверки

```powershell
python -m unittest discover -s tests -v
ruff check .
```

Тесты покрывают измерение и отрисовку текста, безопасные имена и манифест,
настройки, генерацию PNG/PDF, конфликты, отмену и резервную сборку PDF без
`pypdf`.

## Ограничения

- Для TTC-коллекций используется первое начертание; отдельные лица коллекции
  могут быть недоступны по имени.
- Отмена генерации срабатывает между файлами или страницами; один очень
  большой рендер может завершиться перед остановкой.
- Импорт напрямую из Excel или Word не поддерживается – используйте TXT/CSV
  или вставку текста.
- Список ФИО и исключения не сохраняются в настройках автоматически.
- На не-Windows системах тема определяется через доступный Qt-сигнал; если
  он недоступен, используется тёмная тема.

# Пользовательская инструкция

##  Что это

Программа для массового заполнения грамот. Берёт шаблон (JPG/PNG), список ФИО и шрифт — и генерирует готовые грамоты в PDF или PNG.

## Установка

1. Скачай `AutoFill.exe`
2. Запусти — ничего устанавливать не нужно
3. При первом запуске Windows может спросить разрешение — нажми «Разрешить»

## Быстрый старт

1. **Выбери шаблон** — кнопка «Выбрать» рядом с полем «Шаблон грамоты»
2. **Выбери шрифт** — начни вводить название, выбери из подсказок. Или нажми «Файл» для своего TTF/OTF
3. **Укажи размер** — в поле «Размер»
4. **Вставь список ФИО** — в большое поле. Каждая строка — один человек: `Иванов Иван Иванович`
5. **Укажи позицию** — вкладка «Позиция» → «Указать точку на грамоте»
6. **Нажми «Сгенерировать грамоты»**

## Вкладки

### Основные

- Шаблон грамоты
- Шрифт (поиск по системе или свой файл)
- Размер шрифта
- Цвет
- Межбуквенный интервал
- Список ФИО + поиск по списку
- Исключения (кто не влез)

### Позиция

- Выравнивание: по левому краю / по центру
- X, Y — координаты текста
- Автоцентр по X / Y
- Сдвиг X / Y
- Межстрочный интервал
- «Указать точку на грамоте»

### Формат имени

- В одну строку
- Фамилия / Имя Отчество
- Каждое слово отдельно
- Свой вариант (сколько слов на первой строке)
- Авто (по отступу)

### Вывод

- Формат: PNG или PDF
- PDF: каждому свой файл или один общий
- Имя общего PDF
- Папка для сохранения (+ «Обзор»)
- Превью перед генерацией
- Текст для превью: тестовый / самый длинный / свой

### Настройки

- Тема: тёмная / светлая
- О программе, авторы, лицензия

## Окно выбора точки

- **Правая кнопка мыши** — поставить точку
- **Левая кнопка** — перетаскивать грамоту
- **Колесо мыши** — приближение/отдаление
- **Стрелки** — сдвиг точки на 1px
- **Shift + стрелки** — сдвиг на 10px
- **Ctrl + стрелки** — сдвиг на 50px
- **Alt** — показать расстояние от точки до курсора

## Поиск по списку

В поле «Поиск по списку» начни вводить фамилию — список отфильтруется. Можно удалять прямо в режиме поиска — изменения сохранятся.

## Исключения

Если какие-то ФИО не влезают в границы — программа предложит переместить их в «Исключения». Оттуда можно:

- Очистить
- Перенести в основной список
- Скопировать для отдельной генерации с меньшим шрифтом

## Дубликаты

Если в списке есть одинаковые ФИО — программа предупредит и предложит:

- Продолжить
- Удалить дубликаты
- Отмена

## Конфликты файлов

Если файл с таким именем уже существует — предложит:

- Заменить
- Создать с номером (например, `Иванов_Иван_Иванович_1.pdf`)
- Отмена

## Горячие клавиши

В текстовых полях работают стандартные Ctrl+A, Ctrl+C, Ctrl+V.

## Сохранение настроек

При закрытии программа спросит «Сохранить настройки?». Если да — при следующем запуске всё подтянется из `settings.json`.

## Требования

- Windows 10/11
- Не требует установки Python
- Шрифты можно использовать системные или свои TTF/OTF

## main.py
Точка входа. Логика:

1. Создаёт QApplication
2. Загружает style.qss
3. Создаёт DiplomaGenerator
4. Показывает окно
5. Устанавливает цвет заголовка через windows_utils
6. Центрирует окно через screen_utils
7. Запускает event loop

### Важные вызовы
```python
app.setStyleSheet(f.read())  # стили
window = DiplomaGenerator()   # главное окно
window.show()
set_title_bar_color(window, "#222222")
center_window(window)
```

## core/text_render.py

Ядро отрисовки.
### Функции
|Функция|Назначение|

### Anchor'ы
|Anchor|Описание|
|---|---|
|`lm`|left-middle (левый край, центр по вертикали)|

|Функция|Назначение|
|---|---|

# Система ресурсов
### Как это работает
1. **`resources.qrc`** — XML-файл, в котором перечислены все иконки
2. **`resources_rc.py`** — скомпилированная версия ресурсов (генерируется из `.qrc`)
3. **В `main.py`** — импорт `resources_rc` подключает ресурсы
4. **В `style.qss`** — пути к иконкам: `url(":/icons/BlackTheme/check.png")

## ВАЖНО: resources_rc.py должен быть в корне!
**Файл `resources_rc.py` ОБЯЗАТЕЛЬНО должен лежать в корне проекта (рядом с `main.py`).**
Если его там нет — иконки НЕ БУДУТ РАБОТАТЬ!
Проверка:
```bash
# Должен быть виден
dir resources_rc.py
```
Если файла нет — запусти:
```bash
python build.py
```
### Почему иконки не отображаются
| Проблема                            | Решение                                              |
| ----------------------------------- | ---------------------------------------------------- |
| `resources_rc.py` отсутствует       | Запустить `build.py` — он скомпилирует автоматически |
| `resources_rc.py` устарел           | Запустить `build.py` — он проверит дату изменения    |
| Изменены иконки в `icons/`          | Запустить `build.py` — перекомпилирует               |
| Путь в `style.qss` не соответствует | Проверить префикс: `:/icons/путь/к/иконке.png`       |
### resources.qrc должен обновляться при каждом изменении иконок!
**После любых изменений в `resources.qrc` или добавления новых иконок в папку `icons/` — ОБЯЗАТЕЛЬНО перекомпилировать ресурсы!**
```bash
# Ручная компиляция
pyside6-rcc resources.qrc -o resources_rc.py
# Или просто запустить сборку (делает то же самое)
python build.py
```

### Автоматическая компиляция в `build.py`

`build.py` автоматически:

1. Проверяет дату изменения `resources.qrc`
2. Если он новее `resources_rc.py` — перекомпилирует
3. Если `resources_rc.py` отсутствует — создаёт
4. Если `resources.qrc` не изменился — пропускает (экономит время)

### Как добавить новую иконку

1. Положи PNG иконку в нужную папку:

```
icons/BlackTheme/my_icon.png
```

2. Добавь её в `resources.qrc`:
```xml
icons/BlackTheme/my_icon.png
```

3. Перекомпилируй ресурсы:
```bash
python build.py
```
или вручную:
```bash
pyside6-rcc resources.qrc -o resources_rc.py
```

4. Используй в `style.qss`:
```css
image: url(":/icons/BlackTheme/my_icon.png");
```

#  Сборка EXE

```bash
python build.py
```

Что делает `build.py`:

1.  Проверяет наличие `resources.qrc`
2.  Компилирует `resources_rc.py` (если нужно)
3.  Проверяет наличие `app_icon.ico`
4.  Очищает старые сборки
5.  Собирает EXE с PyInstaller

##  Частые ошибки

### 1. Иконки не отображаются в EXE

**Причина:** `resources_rc.py` устарел или отсутствует.

**Решение:** Запусти `python build.py` — перекомпилирует ресурсы.

### 2. ModuleNotFoundError: No module named 'resources_rc'

**Причина:** `resources_rc.py` не в корне проекта.

**Решение:** Перемести `resources_rc.py` в корень или перекомпилируй.

### 3. Иконки видны в IDE, но не в EXE

**Причина:** Пути в `style.qss` не соответствуют ресурсам.

**Решение:** Проверь пути — должны начинаться с `:/icons/`.

### 4. Ошибка: pyside6-rcc not found

**Причина:** PySide6 не установлен или не в PATH.

**Решение:**
```bash
pip install PySide6
```
Или используй полный путь:
```bash
python -c "from PySide6 import pyside6_rcc; pyside6_rcc.main(['resources.qrc', '-o', 'resources_rc.py'])"
```

### 5. Иконки работают в IDE, но не в EXE после перемещения папок
**Причина:** `resources_rc.py` был перемещён в другую папку или удалён.
**Решение:** Верни `resources_rc.py` в корень проекта или перекомпилируй заново:
```bash
pyside6-rcc resources.qrc -o resources_rc.py
```

##  Структура путей в стилях

|Где используется|Какой путь|
|---|---|
|В IDE (разработка)|`url("icons/BlackTheme/check.png")`|
|В EXE (сборка)|`url(":/icons/BlackTheme/check.png")`|
|В ресурсах (`resources.qrc`)|`<file>icons/BlackTheme/check.png</file>`|

**Важно:** Пути в `style.qss` должны быть с префиксом `:/` — это говорит Qt, что иконка из ресурсов, а не с диска.

## Быстрая проверка: загружаются ли иконки

Добавь в `main.py`:

```python
import resources_rc
from PySide6.QtGui import QIcon
```
## Проверка загрузки иконок
```python
icon = QIcon(":/icons/BlackTheme/check.png")
print(f"Чекбокс: {not icon.isNull()}")  # Должно быть True
icon = QIcon(":/icons/BlackTheme/arrow-up.png")
print(f"Стрелка вверх: {not icon.isNull()}")  # Должно быть True
```

Если выводит `False` — ресурсы не скомпилированы или пути не совпадают.
